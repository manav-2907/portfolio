# Manav Narula — Portfolio

My personal portfolio website: AI Engineer specializing in Agentic AI, LLM pipelines, RAG systems, and computer vision.

**🌐 Live: [portfolio-manav-5011.vercel.app](https://portfolio-manav-5011.vercel.app)**

## Highlights

- **Featured projects** — including the [Autonomous AI Career Agent](https://github.com/manav-2907/agentic-ai-task-executor) (LangGraph agent with eval suite + Langfuse observability)
- Terminal-style animated hero, scroll-spy navigation, and count-up stats
- Fully responsive, dark-themed, single-page design
- SEO + Open Graph meta tags

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** — build tooling
- **Tailwind CSS** — styling
- **lucide-react** — icons

## Running Locally

```bash
npm install
npm run dev        # dev server at http://localhost:5173
```

```bash
npm run build      # production build -> dist/
```

## Structure

```
src/
├── main.tsx           # entry point
├── app/App.tsx        # all sections (hero, about, projects, skills, contact)
```
